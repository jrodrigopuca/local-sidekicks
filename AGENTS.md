# Working in this repo

Before any decision that is expensive to undo — the shape of an agent, what
the harness measures, which model is the floor — read [`docs/adr/README.md`](docs/adr/README.md).
An accepted ADR is applied and its "Revisar si" line checked, not re-derived
and not overturned in silence; a changed decision gets a new ADR that
supersedes the old one.
